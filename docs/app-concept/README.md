# ATRIS Mobile App Concept v1

Пакет презентации концепта мобильного хаба АТРИС для партнёров.

## Файлы

| Файл | Назначение |
|------|------------|
| `ATRIS_Mobile_App_Concept_v1.pdf` | **Основной файл для показа / отправки** |
| `presentation.html` | **Веб-презентация** в стиле сайта atris.su (скролл, картинки, тот же текст) |
| `ATRIS_Mobile_App_Concept_v1.html` | Исходник PDF (стиль КП АТРИС, A4) |
| `slides/` | PNG концепт-артов по экранам |

## Слайды

1. Обложка и ценность продукта  
2. Главный хаб  
3. Интерактивная схема DJI AGRAS T50  
4. Материалы узла + таймкоды видео  
5. Каталог запчастей  
6. Калькулятор химии  
7. Чат поддержки  
8. Закрытие / roadmap  

## Как отправлять партнёрам

1. Прикрепить PDF в письмо.  
2. При необходимости — ZIP всей папки `app-concept`.  
3. На встрече — PDF на полный экран или `presentation.html` в браузере (стрелки ↑↓ для навигации).

Статус: **concept UI**, не коммерческое предложение на разработку.
