# ATRIS design system

## Tone

Calm, clean, engineering. Not startup hype. One screen = one idea.

## Layout

- Content width ~1200–1280px
- Generous section gaps; desktop side padding 80–120px
- Predictable 2/3-column grids; no chaotic collage

## Type

Manrope. Short H1/H2. Short paragraphs. High readability.

## Colors / controls

- Primary: `#062554` on white text
- Accent green often `#8DC63F`
- Dark surfaces: `#021228` / `#03173b`
- Radius: buttons 8–12px, cards 12–16px
- Hover: subtle opacity/darken — no jump, glow, neon

## Imagery

Real drones, fields, operators. No abstract CGI / cyber / AI purple gradients.

## Forbidden defaults

AI purple-on-white themes, cream+terracotta serif kits, glassmorphism, emoji decoration, oversized multi-shadows.
